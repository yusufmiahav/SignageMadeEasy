Set up this display

Wi-Fi

Pick your network below and enter its password. The display will try to connect immediately.

IP address

DHCP (automatic) is right for almost every setup — only switch to a static IP if you specifically need this display to always be reachable at the same address.

Local content (fail-safe)

Upload an image, video, or PDF to show directly on this display whenever it can't reach the hub — no network setup needed for this part. It loops on its own until the hub is reachable again, at which point the hub's own content takes back over automatically.

Performance

Caps the CPU's top speed to run cooler — worth trying if this Pi has no heatsink and is throttling from heat. Trades away some headroom, so only needed if that's actually happening.

Reboot required for this to take effect.
